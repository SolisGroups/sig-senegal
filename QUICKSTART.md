# 🚀 DÉMARRAGE RAPIDE - SIG Sénégal

## En 5 Minutes ⏱️

### 1. Accédez à l'Application

```
http://localhost/sig-senegal/
ou
http://localhost:8080/sig-senegal/
```

### 2. La Page se Charge

- Vous verrez une barre de navigation bleue en haut
- Une grande carte au centre
- Un panneau à gauche (couches)
- Un panneau à droite (fonds de carte)
- Une barre d'outils à gauche de la carte

### 3. Explorez les Fonctionnalités

#### Navigation de la Carte

```
- Cliquer et glisser = Déplacer la carte
- Scroll souris = Zoomer
- Boutons +/- = Zoomer précisément
- Bouton Maison = Revenir au Sénégal
```

#### Afficher/Masquer les Couches

```
1. Cliquer sur les cases à cocher du panneau gauche
2. Coché = Couche visible
3. Décoché = Couche cachée
```

#### Rechercher une Localité

```
1. Taper dans la barre de recherche (haut-droit)
2. Appuyer sur Entrée
3. La localité s'affiche et la carte se centre dessus
```

#### Changer le Fond de Carte

```
1. Cliquer sur le panneau droit
2. Sélectionner: OpenStreetMap, Satellite ou Terrain
3. Le fond change immédiatement
```

#### Mesurer une Distance

```
1. Cliquer sur l'icône de règle (barre d'outils gauche)
2. Cliquer sur la carte pour créer des points
3. Double-cliquer pour terminer
4. La distance s'affiche
```

#### Imprimer la Carte

```
1. Cliquer sur l'icône d'impression (barre d'outils)
2. Ou utiliser Ctrl+P
3. Adapter les paramètres et imprimer
```

#### Exporter les Données

```
1. Cliquer sur "Outils" en haut
2. "Télécharger CSV" ou "Télécharger GeoJSON"
3. Le fichier se télécharge
```

## Conseils Utiles 💡

### Affichage Mobile

- Les panneaux se cachent automatiquement
- Cliquer sur les boutons avec barres (bas-droite)
- Pour réafficher les panneaux

### Performance

- Si la carte est lente, masquer certaines couches
- Augmenter le zoom
- Actualiser la page (Ctrl+F5)

### Information sur les Couches

- Cliquer sur une région/localité
- Une popup avec les informations s'affiche
- Cliquer sur la croix pour fermer

### Coordonnées

- Voir la latitude/longitude en bas
- Mise à jour en temps réel
- Voir aussi le niveau de zoom

### Minimap

- Petit carré en bas à droite
- Montre votre position globale
- Pratique pour s'orienter

## Dépannage Rapide 🔧

### "La carte ne charge pas"

```
✓ Rafraîchir la page (Ctrl+F5)
✓ Vérifier la connexion Internet
✓ Ouvrir la console (F12) pour les erreurs
✓ Attendre 5 secondes le chargement complet
```

### "Les couches ne s'affichent pas"

```
✓ Vérifier que les couches sont cochées
✓ Vérifier le zoom (zoom avant parfois nécessaire)
✓ Rafraîchir la page
✓ Consulter la console (F12)
```

### "La carte est lente"

```
✓ Masquer des couches
✓ Augmenter le zoom
✓ Désactiver certains effets
✓ Utiliser une meilleure connexion
```

### "La recherche ne fonctionne pas"

```
✓ Appuyer sur Entrée
✓ Vérifier l'orthographe
✓ Essayer avec moins de caractères
✓ Consulter la console (F12)
```
