SIG Sénégal
============

Projet web cartographique (Leaflet) pour l'affichage des limites administratives, routes et localités du Sénégal.

Guide PWA et Service Worker
---------------------------
Le projet contient un guide dédié et des scripts pour transformer l'application en PWA et gérer le service worker.
Voir : `README-PWA.md` pour les instructions de génération du `sw.js`, la stratégie de cache, et la configuration CI.

Commandes rapides
-----------------
- Installer les dépendances : `npm install`
- Générer `sw.js` localement : `npm run build-sw`
